# Onboarding OpenHikmah (français A2)

> Onboarding en **lecture seule** pour nouveaux contributeurs — basé sur le dépôt, pas le marketing.  
> **Niveau : A2 (CEFR)** — phrases courtes, mots simples, termes tech expliqués.  
> Version complète (français B2+) : [`../onboarding-fr/`](../onboarding-fr/)  
> Version anglaise : [`../onboarding/`](../onboarding/)

## Comment utiliser cette série

1. Lisez les phases **dans l'ordre** (1 → 16).
2. Respectez les balises de preuve : **FACT** (fait vérifié) · **INFERENCE** (déduction) · **UNKNOWN** (inconnu).
3. Les phases 10–12 supposent une app locale (sur votre machine). La phase 12 demande votre accord avant tout changement de code.
4. Quand une phase est finie, répondez **« continuer vers la phase N »** (ou en anglais `continue to Phase N`).
5. Si un mot tech est difficile, cherchez une courte explication entre parenthèses dans le texte.
6. Pour plus de détail ou un français plus avancé, ouvrez la [version B2+](../onboarding-fr/README.md).
